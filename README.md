# Django NoteApp

## Description

Django NoteApp is a simple web application that allows users to create, read, update, and delete (CRUD) personal notes. It features user authentication, ensuring that each user's notes remain private. The app is styled with Bootstrap for a modern and responsive UI.

## Features

- User registration and authentication (Login/Logout)
- Secure user session management
- Add new notes
- View a list of all personal notes
- Update existing notes
- Delete notes
- Fully responsive design using Bootstrap

## Requirements

To run this application, you need to have the following installed:

- Python 3.8+
- Django 4.0+
- SQLite (default Django database, or any other preferred database)

## Installation

1. Clone the repository:
   ```bash
   https://github.com/Ankurgupta2927/Django_NoteApp.git
   ```
   ```
   cd django-noteapp
   ```
   ```
   python -m venv env
   ```
   ```
   source env/bin/activate   # On Windows: env\Scripts\activate
   ```
   ```
   pip install -r requirements.txt
   ```
   ```
   python manage.py migrate
   ```
   ```
   python manage.py runserver
   ```
